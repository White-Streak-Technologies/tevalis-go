# tevalis-go
Unofficial SDK/client wrapper for the Tevalis POS API, intended for third-party integrations.

## Disclaimer
This project is not affiliated with, endorsed by, or supported by Tevalis.

## Running with Go
1. Install Go (1.20+ recommended).
2. From the repository root, run: go run .
3. If you prefer a binary, run: go build . and then execute the generated binary.

## Timestamps
Date timestamps returned by the API are already adjusted to the venue timezone location, as confirmed with the Tevalis API team.
